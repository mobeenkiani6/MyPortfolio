# 🚀 3D Developer Portfolio

A high-performance, Awwwards-Level 3D portfolio featuring interactive geometry, holographic glassmorphism, and dynamic animations. Built to impress, engineered for performance.

## ✨ Key Features
- **Magnetic Physics Cursor**: A custom framer-motion cursor with real-time spring physics and ambient expansion.
- **3D Coverflow Mechanics**: Swiper-powered interactive carousels for Projects & Education with real-time pitch/yaw card tilting and neon glows.
- **Holographic Flip Cards**: CSS `preserve-3d` flip layers featuring sweeping iridescent shimmer-hover gradients.
- **Conveyor Belt Marquee**: Infinite-scrolling pause-on-hover skill belts running on separate X-axes, masked with seamless hardware edge fading.
- **R3F Global Environment**: High-performance Three.js floating geometry and responsive ambient particle systems running natively behind DOM components.
- **Dynamic Vertical Timeline**: Intersection-triggered scroll-based animated timeline with pulsating nodes.
- **Responsive & Modern**: Fully responsive Awwwards-tier architecture.

## 🛠️ Technology Stack
- **Framework**: React 18 (Vite)
- **Styling**: Tailwind CSS
- **3D Engine**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animations**: Framer Motion
- **Carousels**: Swiper.js

## 📦 Local Setup

1. **Clone the repository**
   ```bash
   git clone https://github.com/mobeenkiani6/MyPortfolio.git
   ```
2. **Install dependencies**
   ```bash
   npm install
   ```
3. **Start Development Server**
   ```bash
   npm run dev
   ```
